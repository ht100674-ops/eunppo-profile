StreamShort Studio — Windows Portable

1. ZIP 전체를 쓰기 가능한 일반 폴더에 압축 해제하세요.
2. StreamShortStudio.exe를 더블클릭하세요.
3. Python, pip, FFmpeg 설치는 필요하지 않습니다.
4. 인터넷 연결과 관리자 권한은 편집/출력에 필요하지 않습니다.

_internal 폴더, portable.ini와 동봉 파일을 그대로 유지하세요.
EXE 하나만 바탕화면으로 옮기면 실행되지 않습니다.
바탕화면에는 EXE의 바로가기를 만들면 됩니다.

Windows 10 22H2 / Windows 11 64비트 대상입니다.
서명되지 않은 빌드입니다. 실제 Windows 10/11 클린 PC 검증 여부는
동봉된 BUILD_STATUS.txt와 self-test.json을 확인하세요.

앱이 열리면:
녹화본 불러오기 → IN/OUT → 편집 스튜디오로 추가 → 편집
→ 미리보기 갱신 → MP4 내보내기

편집 기능과 제한 사항: USER_GUIDE.md
오류 정보: Data/error.log 또는 사용자 AppData의 StreamShortStudio/error.log
캐시/복구: 기본적으로 Data/ 폴더. 읽기 전용이면 사용자 AppData로 전환합니다.
원본 영상은 프로젝트에 복사하지 않으며 수정하지 않습니다.
