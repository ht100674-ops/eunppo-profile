# StreamShort Studio 사용 설명서

Portable ZIP 전체를 압축 해제한 뒤 StreamShortStudio.exe를 실행하세요. 별도 도구 설치는 필요 없습니다.

## 사용 순서

### 1. 방송 녹화본 탐색

- `녹화본 불러오기` 또는 파일 드롭. 첫 번째 드롭 파일을 처리합니다.
- 길이/해상도/FPS/코덱을 확인합니다. 전체 원본을 복사하거나 프록시 변환하지 않습니다.
- 슬라이더 또는 `시간 이동`으로 찾습니다. `HH:MM:SS.밀리초`와 초 단위를 입력할 수 있습니다.
- IN/OUT을 입력하거나 현재 위치 버튼을 누릅니다. 한 장면은 최대 180초입니다. 짧은 테스트 클립도 허용합니다.
- 반복 재생 체크는 선택 범위를 반복합니다.
- `구간 목록에 저장`으로 여러 장면을 기록합니다. 이름을 바꾸어 다시 저장하거나 삭제할 수 있습니다.
- `편집 스튜디오로 추가`하면 현재 구간을 프로젝트에 추가합니다.
- MKV 등 원본 재생이 어렵다면 `선택 구간 프록시`로 **그 구간만** 960px 폭 MP4로 변환합니다. 프록시 재생 중 전체 원본 탐색으로 복귀하려면 원본을 다시 불러옵니다.

### 2. 쇼츠 편집

- 원본 영상의 절대 경로, IN/OUT, 배치와 트랙 속성만 프로젝트에 저장됩니다.
- 미디어 목록/영상 타임라인에서 클립을 선택합니다. 노란 재생 헤드를 원하는 지점으로 옮긴 다음 S로 분할합니다.
- Delete로 삭제하고 드래그 또는 앞/뒤 이동 버튼으로 순서를 바꿉니다. 복제도 지원합니다.
- 클립 오른쪽 끝 드래그는 OUT을 바꿉니다. 정확한 IN/OUT은 속성에서 입력합니다.
- 영상 순서 변경/삭제 시 BGM·자막의 시간은 자동으로 당겨지지 않습니다. 필요한 자막/오디오 시간을 따로 맞추세요.
- 자막/오디오 타임라인 몸체 드래그는 시작 시간을 30fps 단위로 이동하고 오른쪽 끝은 길이를 바꿉니다.
- 현재 원본 오디오는 영상 트랙에 묶여 있습니다. 별도 오디오 클립으로 추출하는 기능은 없습니다.
- 타임라인의 영상/오디오/자막 길이는 실제 프로젝트 값이며 렌더에 사용됩니다.

### 3. 배치와 자막

속성에서 배치를 선택합니다.

| 배치 | 동작 |
|---|---|
| crop | 9:16을 가득 채우고 확대(1~4), 가로·세로 위치(0~1) 적용 |
| fit | 영상 전체를 맞추고 남는 부분에 배경색 적용 |
| blur | 원본을 확대·블러 처리한 배경 위에 전체 원본 표시 |
| split | 같은 원본의 서로 다른 크롭 영역을 위·아래에 배치 |

상/하단 크롭은 `x,y,너비,높이`를 원본 크기 대비 0~1로 입력합니다. 영역은 원본 밖으로 벗어날 수 없습니다.
예: 상단 `0,0,1,0.65`, 하단 `0.7,0.55,0.3,0.45`.
원본에 합쳐진 캠/게임을 분리 복원하는 것이 아니라 각 영역을 크롭·확대합니다.
확대/위치 수치는 crop 배치에서 사용됩니다. crop 상태에서 선택 클립의 미리보기를 드래그하면 구도 값이 바뀝니다. 변경 후 미리보기를 갱신하세요.
배치와 자막 스타일은 JSON 프리셋으로 저장하여 같은 종류의 항목에 다시 적용할 수 있습니다.

수동 자막에는 여러 줄, 시작/종료, 설치 폰트, 크기, 색, 외곽선, 그림자, 배경 박스, 위치가 있습니다.
Noto Sans KR 폰트를 포함하며 FFmpeg/Qt가 함께 사용합니다. 폰트 이름은 FFmpeg/libass가 발견할 수 있어야 합니다.
`none`, `fade`, `pop`, `slide`, `scale` 애니메이션은 ASS/libass로 출력합니다. pop/scale은 현재 동일한 가벼운 크기 전환입니다.
글자 크기는 1080px 출력 기준으로 저장하며 720/360p에서는 비례 축소합니다.
안전 영역은 참고 표시이며 출력에 포함되지 않습니다. 사용자가 상단/하단/오른쪽 여백을 조절할 수 있습니다.

### 4. BGM와 효과음

MP3/WAV/M4A/FLAC/OGG를 추가하여 별도 오디오 트랙으로 배치합니다.
속성에서 원본 시작, 프로젝트 시작, 길이, 음량(0~2), 페이드 인/아웃을 조절합니다.
원본 영상 음량은 영상 클립 속성의 volume입니다. 0은 음소거입니다.
전체 혼합 오디오에는 기본 리미터가 적용됩니다.
`선택 썸네일 / 파형 생성`은 선택한 클립의 첫 프레임과 최대 60초의 오디오만 처리합니다.
이 버전의 파형은 좌측 선택 항목 분석창에 표시됩니다. 타임라인 전체 파형이 아닙니다.

### 5. 미리보기와 MP4

- 편집 후 `미리보기 갱신`을 누릅니다. 360p/720p 렌더 파일을 캐시에 만들고 재생합니다.
- 자막, BGM, 배치가 **최종 출력과 같은 엔진**을 통과합니다. 즉시 실시간 합성 미리보기는 아닙니다.
- 변경 후 이전 미리보기의 재생은 막고 갱신 안내를 표시합니다. 텍스트/프리셋 편집을 마친 뒤 갱신하세요.
- `MP4 내보내기`: 720×1280 또는 1080×1920, 30/60fps, H.264 + AAC.
- high/medium/small은 CPU에서 CRF 18/22/27이며 최종 용량은 가변적입니다. 대화창의 용량은 추정값입니다.
- NVENC/QSV/AMF를 선택할 수 있습니다. 사용할 수 없으면 최종 인코딩을 CPU로 다시 시도합니다. 하드웨어 경로는 이번 환경에서 검증하지 않았습니다.
- 중간 클립 합성은 항상 CPU입니다. GPU 디코딩 자동 선택은 구현하지 않았습니다.
- 취소 시 FFmpeg를 종료하고 임시 렌더 폴더를 제거합니다. 성공한 MP4만 최종 경로에 원자적으로 이동합니다. 기존 출력파일은 작업 성공 전까지 유지됩니다.
- 출력 경로가 원본/음악 경로와 같으면 거부합니다. 원본 영상 전체를 재인코딩하지 않습니다.

### 6. 저장/복구

`.sss`는 버전 있는 UTF-8 JSON입니다. 영상 자체를 프로젝트 안에 넣지 않습니다.
저장, 다른 이름 저장, 열기, 30초마다 자동 저장, 시작 시 복구, 최근 목록을 지원합니다.
원본 이동 시 해당 클립을 선택하고 `원본 재연결`합니다. 같은 경로를 쓰는 클립도 함께 갱신합니다.
자동 저장과 캐시는 Qt의 사용자 AppLocalDataLocation 아래에 저장됩니다.
Windows에서는 일반적으로 사용자 AppData 아래입니다. 권한 오류는 상태창에 표시됩니다.
캐시 비우기는 미리보기/썸네일/파형 파일을 지웁니다.

## 단축키

Space 재생/정지 · S 분할 · Delete 삭제 · Ctrl+Z 실행 취소 · Ctrl+Shift+Z 다시 실행 · Ctrl+S 저장.
좌/우는 30fps 기준 1프레임 이동, Ctrl+휠은 타임라인 확대/축소.
입력창에 포커스가 있으면 편집 단축키를 실행하지 않습니다.

## 성능과 한계

- 영상 전체를 RAM에 적재하지 않습니다. FFmpeg 입력 seek + 구간 길이 제한, 파일 기반 캐시를 사용합니다.
- 작업 중 원본 복사/전체 방송 프록시 변환을 하지 않습니다. 렌더용 중간 파일은 선택 클립 분량만 디스크에 둡니다.
- 클립을 순차 처리하며 FFmpeg 인코딩 스레드 2개, 필터 스레드 1개로 제한합니다. 실제 노트북 성능을 보장하지 않습니다.
- 렌더는 중간 정규화 + 최종 합성의 2회 인코딩입니다. 단일 인코딩보다 느리고 디스크 여유가 필요합니다.
- 썸네일/파형 작업은 최대 30/45초 타임아웃, FFprobe는 45초 타임아웃입니다. 렌더 취소와 달리 분석 작업은 즉시 취소되지 않습니다.
- MKV/MOV 지원은 FFmpeg 처리 및 Qt의 해당 코덱 재생 지원 범위에 따릅니다. 원본을 재생할 수 없으면 선택 구간 프록시를 사용하세요.
- 원본 FPS 표시와 별개로 편집 기본 재생 헤드 단위는 30fps입니다.
- 실제 10시간 방송의 VFR, 손상 파일, HDR, 회전 메타데이터, 다중 오디오 스트림은 추가 검증이 필요합니다. 첫 영상/첫 오디오 스트림을 사용합니다.
- 8GB/16GB 노트북, Windows 10/11 GPU 및 오디오 장치, macOS는 미검증입니다.
